# Implementation plan and status

1. Model mess-scoped users, periods, occupancy, rent, utilities, independent accounts, meals, purchases, advances, fund ledger, statements and audit.
2. Implement exact money allocation and transactional financial services with authorization and idempotency.
3. Expose validated session-authenticated REST routes, then build a responsive bilingual React client connected to them.
4. Add exports, PWA, seed data and automated checks. Verify against the acceptance fixture in the proposal.

The current proposal is `MessLedger_Proposal_v3.pdf`, which appeared during implementation and formalizes the Node/TypeScript architecture. The requested Markdown copy was absent from the initial repository. The v2 proposal remains historical in Git.
